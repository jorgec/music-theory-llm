## Chromatic Approach Techniques

### What Are Chromatic Approaches?

Chromatic approach notes are **non-chord tones** that lead into chord tones by **half-step** motion, creating tension and resolution. They make melodies more sophisticated and connected to the underlying harmony.

### Types of Chromatic Approaches

#### 1. **Single Chromatic Approach** (from below or above)
- **From below**: approach target from 1 semitone below
- **From above**: approach target from 1 semitone above

**Example - Approaching the 3rd of C major (E)**:
```
From below: D# → E (interval pattern: [4, 5] - chromatic half-step up)
From above: F → E  (interval pattern: [5, 4] - chromatic half-step down)
```

#### 2. **Double Chromatic Approach** (enclosure)
- Surround target note from both sides
- Most common in bebop and jazz

**Example - Enclosing the 3rd (E)**:
```
D# → F → E  (below, above, target)
F → D# → E  (above, below, target)
```

**Interval pattern**: `[4, 5, 4]` or `[5, 4, 5]`

#### 3. **Diatonic-Chromatic Approach**
- Combine scale tones with chromatic approaches
- Creates more melodic, less "outside" sound

**Example - Approaching root (C)**:
```
A → B → C  (diatonic: 6th → 7th → root)
A → Bb → B → C  (diatonic + chromatic)
```

**Interval pattern**: `[9, 10, 11, 12]` (adds Bb as chromatic passing tone)

#### 4. **Delayed Resolution**
- Chromatic approach + overshoot, then resolve
- Creates anticipation

**Example**:
```
Target = E (3rd)
D# → F# → E  (approach from below, overshoot, resolve)
```

**Interval pattern**: `[4, 6, 4]`

## Target Notes by Style

### Jazz/Bebop
**Primary targets**: Chord tones (R, 3, 5, 7) + extensions (9, 11, 13)
- **On beats 1 & 3**: Target chord tones or extensions
- **On beats 2 & 4**: Chromatic approaches allowed

**Example over Dm7**:
```
Chord tones: D (R), F (3), A (5), C (7)
Extensions: E (9), G (11), B (13)
Chromatic approaches: C#→D, E→F, G#→A, B→C
```

### Blues
**Primary targets**: Blues scale tones (R, b3, 4, b5, 5, b7) + extensions
- **Blues note (b5)**: Already chromatic, use as approach to 5th
- **Tension notes**: b3, b7 → resolve to R or 3rd

**Example over A7 blues**:
```
Targets: A (R), C (b3), D (4), Eb (b5), E (5), G (b7)
Chromatic approaches: G#→A, B→C, D#→E, F#→G
```

### Soul/Funk
**Primary targets**: Root, 3rd, 7th of chord + characteristic 6th
- **Groove-oriented**: Target notes on strong beats (1, 3)
- **Chromatic fills**: Between chord hits

**Example over Dm7 (soul)**:
```
Targets: D (R), F (3), C (7), B (6)
Chromatic fills: C#→D→C#→D (tonic oscillation)
               E→F→E (3rd ornament)
```

### Pop/Rock
**Primary targets**: Root, 3rd, 5th (triadic)
- **Simpler approaches**: Mostly single chromatic, not double
- **Memorable hooks**: Target notes on strong syllables/beats

## Playing the Changes

### What Does "Playing the Changes" Mean?

**Definition**: Improvising melodies that explicitly outline the chord progression, hitting chord tones and extensions at key moments, rather than staying in one scale.

**Key Principle**: Your melody changes as the chords change, emphasizing notes that define each chord's quality and function.

### Fundamental Concepts

#### 1. **Chord Tone Targets**
Land on chord tones (especially 3rd and 7th) when chords change.

**Example - ii-V-I in C**:
```
Dm7     | G7      | Cmaj7   |
F (3rd) | B (3rd) | E (3rd) |  ← All 3rds hit on beat 1
```

#### 2. **Guide Tones** (3rds and 7ths)
These define chord quality and create smooth voice leading.

**Example - ii-V-I guide tone line**:
```
Dm7: F (3), C (7)  →  G7: F (7), B (3)  →  Cmaj7: E (3), B (7)
                 ↓                   ↓                    ↓
        Half-step motion: C → B, then B (common tone)
```

**Lick using guide tones**:
```
Intervals: [5, 10, 11, 4, 11]
Notes:     F, C,  B,  E, B   (over Dm7-G7-Cmaj7)
           ↑  ↑   ↑   ↑  ↑
           3  7   3   3  7  (chord tones)
```

#### 3. **Arpeggio Motion**
Outline each chord with arpeggios, connecting them with chromatic approaches.

**Example - ii-V-I with chromatic connections**:
```
Dm7: D, F, A, C         (0, 5, 9, 12)
[chromatic approach]    B (11)
G7:  B, D, F, A        (11, 14, 17, 21)
[chromatic approach]    G# (20)
Cmaj7: G, B, E         (19, 23, 16)
```

**Full interval pattern**: `[0, 5, 9, 12, 11, 14, 17, 21, 20, 23, 16]`

#### 4. **Scalar Approach with Chord Emphasis**
Play scales, but emphasize chord tones on strong beats.

**Example - Dm7 (Dorian)**:
```
Beat 1: D (root)     ← Strong
Beat 2: E (9th)      ← Passing
Beat 3: F (3rd)      ← Strong
Beat 4: G (11th)     ← Passing
Beat 1: A (5th)      ← Strong
```

## Bebop/Jazz Vocabulary

### Essential Bebop Techniques

#### 1. **Bebop Scale** (8-note scale)
Add chromatic passing tone to create even 8-note pattern for 8th-note lines.

**Dominant Bebop Scale** (over G7):
```
G, A, B, C, D, E, F, F# (→G)
0, 2, 4, 5, 7, 9, 10, 11, 12

Chromatic passing tone: F# between F (b7) and G (root)
```

**Major Bebop Scale** (over Cmaj7):
```
C, D, E, F, G, G#, A, B (→C)
0, 2, 4, 5, 7, 8, 9, 11, 12

Chromatic passing tone: G# between G (5) and A (6)
```

#### 2. **Enclosures** (Surrounding Target Notes)
Approach target from both above and below.

**Diatonic Enclosure**:
```
Target = C (root)
B → D → C  (from below scale tone, above scale tone, target)
```

**Chromatic Enclosure**:
```
Target = E (3rd)
D# → F → E  (chromatic below, chromatic above, target)
```

**Mixed Enclosure** (most common):
```
Target = E (3rd)
D → F → E  (diatonic below, diatonic above, target)
D# → F → E (chromatic below, diatonic above, target)
```

#### 3. **Turn-Around Licks** (ii-V-I)
Standard jazz vocabulary for cadences.

**Classic ii-V-I line**:
```
Dm7:  D, F, A       (0, 5, 9)
G7:   Ab, B, D, F   (8, 11, 14, 17) ← Ab is chromatic approach
Cmaj7: E, G, B      (16, 19, 23)
```

**Interval pattern**: `[0, 5, 9, 8, 11, 14, 17, 16, 19, 23]`

#### 4. **Tritone Substitution Lines**
Play altered dominant a tritone away.

**Over G7 → Cmaj7**:
```
Instead of G7 (G-B-D-F), play Db7 (Db-F-Ab-Cb)
Same 3rd (F) and b7 (Cb/B)!

Line: Db, E, F, Ab → resolves to C, E, G
```

**Interval pattern**: `[1, 4, 5, 8, 0, 4, 7]`

#### 5. **Parker/Gillespie Licks**
Characteristic bebop phrases.

**Charlie Parker "Bird Lick"** (over ii-V):
```
Dm7: F, E, D, C, A      (5, 4, 2, 0, 9)
G7:  B, G, F, D         (11, 7, 5, 2)

Uses: Chromatic descent + arpeggios + guide tones
```

## Implementation Checklist

For every new lick, ensure:

### ✅ Chromatic Sophistication
- [ ] At least 1-2 chromatic approaches to chord tones
- [ ] Target notes clearly identified (3rd, 7th, extensions)
- [ ] Chromatic motion is melodically and harmonically relevant

### ✅ Playing the Changes
- [ ] Chord context explicitly stated
- [ ] Functional harmony described (ii-V-I, I-IV-V, etc.)
- [ ] Lick outlines chord progression, not just one scale

### ✅ Bebop/Jazz Vocabulary
- [ ] Uses enclosures, guide tones, or bebop scales (for jazz/advanced)
- [ ] Features extensions (9, 11, 13) or alterations (b9, #9, etc.)
- [ ] Demonstrates resolution patterns

### ✅ Style-Appropriate
- [ ] Matches target style characteristics
- [ ] Uses appropriate techniques for genre
- [ ] Rhythmic feel matches style (swing, straight, syncopated)

### ✅ Complete Documentation
- [ ] Description includes harmonic context
- [ ] `chord_context` field populated
- [ ] `functional_harmony` field populated
- [ ] `target_notes` explained
- [ ] `techniques` list comprehensive

## Quick Reference: Common Chromatic Approaches

| Target Note | From Below | From Above | Enclosure |
|-------------|------------|------------|-----------|
| Root (C) | B (11) | Db (1) | B-Db-C or Db-B-C |
| 3rd (E) | D# (4) | F (5) | D#-F-E or D-F-E |
| 5th (G) | F# (6) | Ab (8) | F#-Ab-G or F#-A-G |
| 7th (B) | Bb (10) | C (12) | Bb-C-B or A-C-B |
| 9th (D) | C# (1) | Eb (3) | C#-Eb-D or C-Eb-D |
